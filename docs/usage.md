# Taildesk 使用指南

## 从设备列表连接

先选择或添加目标电脑，检查 VNC 服务，再连接桌面。设备卡片的「…」可以编辑或移除设备；移除会要求确认。网关最多保存 50 台设备，允许最多 8 个并发远控连接。

「服务可达」是最近一次检测结果，不保证电脑持续在线。Mac 的睡眠、Tailscale 状态和屏幕共享设置会影响连接。

## 把空间留给画面

进入桌面时操作区默认收起，可点顶部或右下角「操作」展开：

- 左侧：圆形鼠标摇杆、左键、右键。
- 右侧：键盘、悬浮 / 底置、退格、Enter。
- 中间底部：一行可左右滑动的常用键，包括 Esc、Tab、方向键等。

默认全部悬浮在画面上。「底置」只将底部单行按键放到画面下方，左右控制仍然悬浮。文字、屏幕键盘和快捷键面板也独立悬浮，关闭后可以继续查看完整桌面。

## 鼠标、拖拽与查看

推摇杆移动鼠标，推得越远移动越快，松手停止。按左键单击，按右键打开上下文菜单；按住左键，同时用另一根手指推摇杆可拖拽。

页面指针和光圈表示本页面最后发送的鼠标位置。电脑本地鼠标的移动若没有被 VNC 服务报告，页面不会自动知道其位置。「设置 → 定位鼠标」可以将鼠标移到当前查看区域中央。

也可直接点按远程画面，使用 noVNC 提供的触控手势。触控精度和系统手势的冲突取决于浏览器；精细操作建议用摇杆。

「平移」切换到原始尺寸后拖动画面；「恢复适应」回到完整视图。「只读」停止向远端发送输入，仍可查看和平移；「恢复控制」继续操作。

## 输入文字与快捷键

输入面板有三种方式，切换时保留未发送的文字：

| 方式 | 适合的任务 |
| --- | --- |
| 文字输入 | 用手机输入法编辑一段文字，再点发送；中文效果依赖远端 VNC 和输入法 |
| 屏幕键盘 | 直接发送字母、数字、符号、空格、退格或 Enter |
| 快捷键 | 导航、编辑、F1–F12、Mac / 系统操作 |

Command / Control / Option / Shift 可以组合选择，作用于下一次页面按键，发送后自动释放。需要字母组合键时先选修饰键，再切到屏幕键盘输入字母。外接实体键盘使用自身修饰键。

文字发送使用 Unicode keysym；剪贴板同步需要服务端支持，不能保证所有 macOS / VNC 组合都能直接粘贴。先用短文本确认效果。

## 横屏与系统键盘

可以直接横拿手机，也可点「横屏」让页面内的桌面和控制区旋转；点「退出横屏」恢复跟随窗口。切换不会重连，也不修改电脑分辨率。

iPhone 自带键盘的方向由系统控制。需要横屏中文输入法时，关闭手机的竖屏锁定再横拿手机。手动旋转网页无法改变系统键盘方向；页面自带的屏幕键盘会跟随页面。Safari 的工具栏、全屏和安全区行为也由系统决定。

## 多屏区域

「设置 → 屏幕」中可以选择完整桌面，或服务端报告的某个显示区域。如果没有自动识别：

1. 确认完整桌面确实包含多个显示器。
2. 选择左右 / 上下排列；两屏可调分界比例，三至四屏默认均分。
3. 不规则布局用自定义区域，填写每屏在完整桌面中的 X、Y、宽、高。

布局保存在当前浏览器中，并区分设备。桌面分辨率变化后，自定义像素区域会停用，需要重新保存。

区域选择只裁剪已经收到的画面；不能显示 VNC 没有传来的屏幕，不会改变 Mac 的显示器设置，也不减少完整桌面的传输量。自动识别依赖标准 ExtendedDesktopSize 扩展；不同 macOS 版本可能返回不同布局。

## 连接质量和恢复

「设置」中的流畅 / 均衡 / 清晰向服务端请求不同质量和压缩参数，实际效果依赖其支持的编码。「到网关」测量网页到网关的 HTTP 往返时间，不代表完整的鼠标到画面延迟。

临时中断后会按 2、4、8、15、30 秒退避重试，后续最多每 30 秒重试一次；稳定连接后重置间隔。也可立即重连，或返回设备列表停止。后台暂停重试，回到前台继续；浏览器的离线提示只影响重试速度，不会据此主动切断正常桌面。

认证失败会停止重试。网关重启或会话过期后需重新登录，重连时也可能需要再次输入 VNC 密码。排查时可以记录关闭原因和编号；分享截图前遮住设备地址、名称和桌面内容。
